# Alexandra Stankovičová — osobné portfólio

Vitaj na mojom osobnom portfóliu. Tento projekt je vytvorený ako vizuálna prezentácia mojej tvorby, nápadov a webových projektov. Cieľom je ukázať dizajn, zmysel pre detail a schopnosť vytvárať stránky, ktoré sú nielen pekné, ale aj príjemné na používanie.

## O projekte

Táto stránka slúži ako môj online priestor pre:

- prezentáciu projektov a prác,
- zdieľanie tvorivých myšlienok,
- ukážku webového dizajnu a frontendových zručností,
- vytvorenie jedinečného a ľahko rozpoznateľného vizuálneho štýlu.

## Spustenie projektu

Nie je potrebná žiadna inštalácia. Stačí otvoriť súbor `index.html` v prehliadači alebo použiť náhľad v VS Code.

### Možnosti:

1. Otvor súbor `index.html` priamo v editore.
2. Klikni pravým tlačidlom myši na `index.html` a zvoľ `Open with Live Preview` alebo `Show Preview`.
3. Ak pracuješ v GitHub Codespaces, môžeš projekt otvoriť priamo z GitHub a následne spustiť náhľad v editori.

## Štruktúra projektu

| Súbor / priečinok | Popis |
| ----------------- | ----- |
| `index.html` | Hlavná stránka portfólia s obsahom a sekciami. |
| `styles.css` | Štýly, farby, rozloženie a vizuálne úpravy. |
| `script.js` | Interaktívne prvky a logika pre menu a animácie. |
| `img/` | Obrázky, ilustrácie a ďalšie vizuálne zdroje. |
| `docs/` | Dokumentácia, dizajn referencie a ďalšie materiály k projektu. |
| `.gitignore` | Určené pre ignorovanie súborov, ktoré sa nemajú commitovať. |

## Funkcie

- moderný a čistý dizajn,
- responzívna štruktúra pre rôzne veľkosti obrazovky,
- sekcie pre projekty, o mne a kontakt,
- vizuálne prvky a grafická identita portfólia,
- jednoduchý a ľahko upraviteľný HTML/CSS setup.

## Rozvoj a úpravy

Projekt je navrhnutý tak, aby sa dal jednoduchšie rozširovať. Môžeš upravovať:

- texty v sekciách,
- farby a typografiu v `styles.css`,
- obsah projektov v `index.html`,
- obrázky v priečinku `img/`.

## Bezpečnosť

Pri vývoji a publikovaní webu nepoužívaj skutočné heslá, API kľúče ani citlivé údaje. Všetky informácie by mali byť výlučne testovacie alebo verejne dostupné.

## Záver

Tento projekt je zárodkom môjho online priestoru a zároveň praktickou ukážkou toho, ako môžu byť webové stránky vizuálne atraktívne, funkčné a osobité. Je to miesto, kde sa dá rýchlo experimentovať, rozvíjať dizajn a budovať vlastnú digitálnu identitu.
